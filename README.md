# Charte du bénévole : Institut du Numérique Responsable

Charte définissant les règles de contribution (bénévolat, adhésion, mission ponctuelle) à l'Institut du Numérique Responsable (INR) : rôles et engagements, propriété intellectuelle, données personnelles, usage responsable du numérique.

**Statut : brouillon, à valider par le Conseil d'Administration.**
